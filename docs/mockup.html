请解释为什么在页面置换算法中，FIFO 会出现 Belady 异常，而 LRU 不会？
AI
OS 教学助教

核心原因在于**堆栈类算法（Stack Algorithm）**的数学性质差异：

  • LRU 是堆栈类算法：满足包容性质 $S(n) \subseteq S(n+1)$。分配 $n$ 块时留在内存的集合永远是分配 $n+1$ 块时的子集，因此绝对不会产生 Belady 异常。
  • FIFO 不是堆栈类算法：仅依据入队先后淘汰，较早进入的页面可能立刻再次被需要。
// FIFO 淘汰队列头部的最老页面 int victim_frame = frame_queue.pop_front();
