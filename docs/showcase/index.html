📖 经典 PV 原语伪代码执行逻辑联动
// 生产者 Producer 逻辑
1: item = produce_item();
2: P(empty); // 申请空槽位 (可能阻塞)
3: P(mutex); // 抢占临界区互斥锁
4: insert_item(item); // 写入缓冲区槽位
5: V(mutex); // 释放互斥锁
6: V(full); // 唤醒可能阻塞的消费者
// 消费者 Consumer 逻辑
1: P(full); // 检查是否有可用产品 (可能阻塞)
2: P(mutex); // 抢占临界区互斥锁
3: item = remove_item(); // 取出产品
4: V(mutex); // 释放互斥锁
5: V(empty); // 唤醒可能阻塞的生产者
6: consume_item(item);
